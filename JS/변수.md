# 자바스크립트의 변수

## let의 중복선언과 재할당

let에서는 중복선언을 허용하지 않는다.중복 선언을 할 경우 ```syntaxerror```이 발생하게 된다.    
재할당은 가능하다.

## const의 중복선언과 재할당

const에서도 let과 동일하게 중복선언을 허용하지 않는다.   
그리고 const는 다른 변수들과 다르게 재할당도 불가능하다.    
이유는 const는 상수를 선언하는 키워드이기 때문이다.     
처음 선언과 초기화를 하고나면 다른값을 재할당할수없다.    

## let과 const의 스코프 범위

let과 const는 블록 단위 스코프이다.     
```
function hello() {
	let a = 5;
    console.log(a); // 5
}

console.log(a); // ReferenceError: a is not defined
```
{} 블록 내부에서 선언된 let,const변수는 외부에서 참조되지 않는다.

## let과 const의 호이스팅

```
console.log(a);  // ReferenceError :: 변수 선언 이전에 변수 참조 불가능

let a  // 초기화

console.log(a);  // undefined

a = 10  // 할당

consloe.log(a);  // 10
```
선언된 변수를 앞에서 앞에서 참조하려고 하니 에러가 발생한다.   
호이스팅이 발생하지 않는것 처럼 보일수있는데, 이런현상은 let,const의 호이스팅과정이 좀 다르기 때문이다,    

let,const로 변수를 선언하는 경우에는,변수의 선언과 초기화 사이에 일시적으로 변수값을 참조할 수 없는 구간인 **TDZ**라는 구간이 존재해서 그렇다.

호이스팅은 발생하지만,값을 참조할수 없어서 동작하지 않는것 처럼 보인다.
