# 함수

함수는 다른객체처럼 속성및 method를 가질수 있어서 일급객체이다

## 함수를 사용하는 이유

* 코드를 재사용할수있다
* 동일한 코드를 여러 번 사용할수있다

## 함수의 특징

함수가 값이기 때문에 변수안에 담길수 있고,method로 담길수 있다.그리고 함수의 return값으로도 사용할수있다.

## 함수 선언식과 함수 표현식

```
function addOne(x) {
  var y = x + 1;
  return y;
}
```
이것은 함수 선언식이다

```
var addOne = function(x) {
  var y = x + 1;
  return y;
};
```
이것은 함수 표현식이다

### 차이

함수 선언식은 function으로 시작하고 함수의 이름이 반드시 있어야 한다. 특징으로는 *호이스팅*이 적용된다.
호이스팅은 함수가 선언된 위치보다 위에서 함수를 호출해도 에러없이 실행된다는 말이다.

함수 표현식은 호이스팅이 적용되지않아서 함수가 선언되고 난후에 호출해야 에러가 뜨지않는다

## 화살표 함수

화살표함수는 function키워드를 사용해 만든함수보다 간단히 표현할수있어서 사용한다 
```
const add = function(a, b) {
    return a + b;
};

add(1, 2); // 3
```
만약 이런 함수가 있다고하면 이함수에서 function을 지우고 옆에 =>를 붙여서 쓰면 화살표 함수가 된다.
```
const add = (a, b) => {
    return a + b;
};

add(1, 2); // 3
```
그리고 화살표함수는 만약 하나의 매개변수인 경우에는 소괄호를 생략할수있다 예를 들어
```
const func = (param) => {...}
```
이렇게 표현됐다면 param을 괄호를 씌우지 않고 써도 문법에 어긋나지 않는다는 말이다

그리고 함수 내부가 단일표현식 즉 결과가 하나이면 return키워드를 생략이 가능하다

그리고 중복된 매개변수이름을 선언할수없다
