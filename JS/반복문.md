# 반복문

## for

가장 기본적인 for문을 예로 들면
```
for(let i = 0; i<10; i++){
	console.log(i);
}
```
코드를 해석해보면,```let i=0```:이 부분을 초기값이라고 한다. 초기값은 0이다라는 뜻이다. ```i<10```:이부분은 조건부분이고 i가 10미만이라는 조건을 가진다는 뜻이다.false가 되면 멈춘다.```i++```:이부분은 코드가 실행된후 작업할것을 적는다.i값을 1증가한다는 뜻이다

## while

```
let i = 0;

while(i<10){
	console.log(i);
	i++;
}
```
while 다음에 조건을 입력한다.그리고 console.log를 통해 i를 출력하고
i++를 만나서 i에 1을 더한다.이걸 조건이 false가 될때 까지 반복한다.
