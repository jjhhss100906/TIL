# 자료구조

## 배열
* array(배열):여러값을 순서대로 저장하는 자료구조
데이터를 넣을때는 대괄호로 묶은뒤 그안에 자료를 넣는다.배열은 데이터에 각각번호가 붙는데 이번호를 *인덱스*라고 한다. 그리고 0부터 시작한다

## 배열의 특징
1. 순서가 있다   
순서가 있기때문에 순서가 필요한 데이터에 많이쓴다
2. 같은 종류 데이터 저장에 좋다   
예를 들어 숫자들끼리나 이름들끼리 저장하는데 유용하다
3. 크기가 변할수있다   
중간에 추가나 삭제가 가능하다. 추가할때는 push를 쓰고 삭제할때는 pop을 쓴다

## 객체

* object(객체):데이터를 이름표로 관리하는 구조
예를 들어 name :"David",age : 17로 저장했다면
name -> 이름  age -> 나이  이렇게 이름표가 붙어있다
이걸 배열로하면 뭐가뭔지헷갈리는데 객체로 하면 훨씬 보기쉽다

## 객체의 특징

1. key-value구조   
```이름표 : 값``` 이런형태이다
2. 순서보다 객체의 의미가 더 중요하다
3. 현실 세게 표현에 좋다   
사람이나 상품 자동차같은 정보 묶음에 최적화 되어있다
